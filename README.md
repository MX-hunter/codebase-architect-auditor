# Codebase Architect & Security Auditor Skill

An advanced AI assistant skill designed for full-codebase analysis, structural mapping, segmented execution path analysis, automated security auditing (OWASP standards), dependency vulnerability scanning, and documentation generation.

## Features
- **Initial Codebase Dissection:** Deep structural scan on first run.
- **Segmented Path Analysis:** Trace routes, middleware, and controllers.
- **Security & Vulnerability Auditing:** Detect injection flaws, hardcoded secrets, and server exposure risks.
- **Token Optimization:** Uses state files and delta updates to minimize context window bloat.
- **Advanced Scaffolding:** Generate Mermaid sequence diagrams, OpenAPI specs, and unit test templates.
